📸

Focus Hunter

负责人：开场裁判时间：10秒站位＋20秒拍摄；戴眼罩不计时最高奖励：100两Bingo完成：双方都完成规定一轮，即完成该Bingo格。⌄

所需物料

手机1部、眼罩1个、计时器、1—6号标识、中心区与活动边界标记、计分表。

游戏流程

记住站位，蒙眼拍到从头到脚完整的目标成员。

  1. 两队PK：A拍B，再B拍A。每队1名拍摄者、6名目标；6人队可在交换角色后兼任。三场依次进行，其余四队观看。
  2. 前10秒，目标在规定范围内选位置、方向和姿势；拍摄者可观察，不可拍照。目标之间不能完全遮住身体。
  3. 锁定站位后戴眼罩，准备时间不计入30秒。后20秒蒙眼拍摄，最多5张；拍摄者只在中心区原地调整角度，目标保持位置和姿势。
  4. 裁判审核时间顺序前5张：头到脚完整、能辨认成员即算，稍模糊也可；同一人只算一次。一张可以算多人，超过5张的部分不算。
  5. 双方都完成后盖对应格；三场结束，全队统一出发。
银票结算每拍到1名不同成员＋10两；拍齐6人额外＋40两，最高100两。双方分别结算，不另设PK胜负奖金。

判定标准

只审核按拍摄时间排序的前5张。人物须从头到脚完整入镜并能确认身份；人脸清晰度不作为主要判定条件。同一成员只算一次。

禁止事项：不使用Live／动态照片、连拍、视频或后期处理；不摘眼罩、不删照片补拍，旁人不指方向。

工作人员注意

先核对6名目标的编号。戴眼罩准备不计入30秒；三场依次进行，四队旁观，全部结束再统一出发。

结算例子：前5张完整拍到4名不同成员，得40两；拍齐6人得60＋40＝100两。第6张照片不计。

Brick Bank

负责人：Maggie时间：3组模型｜还原共3分钟＋每组观察30秒最高奖励：100两Bingo完成：按顺序挑战至3组完成或3分钟还原时间用完，即完成该格；不得弃权换章。⌄

所需物料

6色DUPLO两套（每套6块）、3组模型搭建图、遮挡物、计时器。展示组按图重搭，队伍始终使用同一套6块。

游戏流程

用6块不同颜色的DUPLO，连续还原3组逐渐变难的模型。

  1. 按顺序挑战3组模型，每组6块不同颜色的DUPLO；每组先观察30秒，可看指定3个面。
  2. 遮住模型后还原，3组共用3分钟；全队可讨论和动手。颜色、位置、方向全部正确才得分。
  3. 喊“提交”后全员停手，Maggie暂停计时核验，只判对错、不指出错误。答对才进入下一组，不能跳组。
  4. 观察与核验不计入还原时间；时间用完即结束，未完整还原的模型不计部分分。
银票结算每完整还原1组＋30两；3组全对再＋10两，最高100两。

判定标准

模型颜色、位置和方向全部一致才算成功；未完成的模型不计部分分。

禁止事项：不能拍照、记录、触碰展示模型或额外回看；暂停核验时不能动手修改。

工作人员注意

观察和核验暂停还原计时。提交后全员停手；只判对错、不指出错误，答对后才进下一组。

结算例子：前两组共用2分钟，第3组用完剩余1分钟仍有一块方向不对，最终60两。

BSO Code Breaker

负责人：Phillis时间：5题 × 30秒｜五题作答累计≤90秒有加奖最高奖励：120两Bingo完成：完成5题正式作答或等待各题限时结束，即完成该格。⌄

所需物料

0—9数字卡（按题库补足重复数字）、5道公司／BSO题与答案表、逐题计时器及总计时器。

游戏流程

解出公司／BSO数字问题，再由队员举卡排出答案。

  1. Phillis公布一道公司／BSO数字题，读完后开始该题30秒计时，全队讨论答案。
  2. 队员一人举一张数字牌，从裁判视角左到右排好；喊“提交”即锁定，不能修改。
  3. 每题只交一次；答错或超时0分。五题实际作答时间累计，读题、判分和收牌不计时。
  4. 5题全部答对且累计≤90秒，加20两；超90秒但五题全对，得100两。
银票结算每题答对＋20两；5题全对且累计作答≤90秒，再＋20两，最高120两。

判定标准

每题只提交一次；从裁判视角左到右数字顺序与答案一致才得分，错答或超时0两。

禁止事项：不搜索、不用AI或计算器，不在提交后换牌或改站位。

工作人员注意

记录5题实际作答秒数，读题、判分、收牌不计入；全对且累计≤90秒才发加奖。

结算例子：五题全对，作答累计85秒，得120两；累计95秒，得100两。

MINI BINGO

负责人：Ricky时间：3名队员各投1次｜约3分钟最高奖励：160两Bingo完成：完成3次正式投掷，即完成该格。⌄

所需物料

九宫格场地绳、砂锅软玩偶1个（锅身贴中心标记）、投掷线、计分表。

游戏流程

将砂锅玩偶投进九宫格，累计银票；3个不同格连线再拿50两。

  1. 全队选3名不同队员，各在线后投1次；投完由Ricky报分、捡回，再投下一次。
  2. 按玩偶静止后“锅身中心标记”所在格得分，锅柄和边缘不影响；重复投中同格仍得分。
  3. 中心压内部线，取相邻格较低分；中心压外边界或出界，得0分。先落地再滑动，按最终位置算。
  4. 占领3个不同格并连成横、竖或对角线，额外＋50两，只加一次；本关连线与整张任务卡的首次Bingo分开算。
银票结算3次格分相加；3个不同格连线再＋50两，最高160两。

判定标准

玩偶静止后只看锅身中心标记；压内线取相邻较低分，压外边界或出界0两。

禁止事项：不助跑、不越线、不移动场地绳；越线一投0分，不补投。

工作人员注意

固定3名不同队员各投一次。每投后报分、登记落点再捡回；连线必须占3个不同格，同格重复命中仍累计格分。

结算例子：中排30＋50＋30，再加连线50＝160两。三次都中50格得150两，没有连线奖。

Code Talker

负责人：Ellen时间：8题，每题20秒；约4分钟最高奖励：100两Bingo完成：完成8题正式挑战，即完成该格；得分按答对题数算。⌄

所需物料

8张正式题卡、备用题卡、计时器；每卡含1个目标词＋3个禁词。

游戏流程

避开目标词中的字、谐音与3个禁词，让队友猜中。

  1. 队员轮流描述，其他人猜；每题20秒，猜对立即换下一题。
  2. 描述者不能说目标词中的字、这些字的谐音或卡上3个禁词；其余描述、举例和动作都可以。
  3. 先违规，本题失败；先被Ellen确认猜对，本题结束。先后由Ellen判定，猜词者不受禁词限制。
  4. 共8题，超时、违规或跳过均记0分，不重来。
银票结算每猜对1题＋10两；8题全对再＋20两，最高100两。

判定标准

先违规则失败；先被Ellen确认猜对则结束。猜词者不受禁词限制，先后由Ellen判定。

禁止事项：不能让队友看到题卡；描述者须避开目标词文字、谐音和3个禁词。

工作人员注意

每张题卡包含目标词和3个禁词。正式开始前说明目标词文字、谐音也不能说，题目失败不重来。

结算例子：目标“火锅”，禁词“辣、涮、聚餐”。可说“大家把食材放进热汤里煮”；描述者说出“锅”则本题失败。

Blind Shape

负责人：Ella时间：4轮，每轮60秒；含换场约6分钟最高奖励：100两Bingo完成：完成4轮正式挑战，即完成该格。⌄

所需物料

8米软绳 × 1、眼罩 × 6—8、4张图形卡、计时器。

游戏流程

全队蒙眼，握住同一根绳子合作摆出目标图形。

  1. 全队戴眼罩，共同握住8米软绳；Ella公布本轮目标图形。
  2. 每轮60秒，可交流、慢慢移动和沿绳调整；每人至少一只手始终握绳。
  3. 时间到立即定型，由Ella主观判断是否成功；以Ella当场判定为准。
  4. 共4轮，判完再摘眼罩、准备下一轮。
银票结算每成功1轮＋20两；4轮全部成功额外＋20两，最高100两。

判定标准

由Ella主观判断图形是否成功，以Ella当场判定为准。

禁止事项：不能偷看、完全松绳或让旁人指挥；绳子不绕颈部，身体不适立即停下。

工作人员注意

在平坦空地进行。每轮到时立即定型，判完后才摘眼罩；每人至少一只手始终握绳。

结算例子：三角形、菱形、五边形成功，正方形未通过，共60两；4轮全成功为80＋20＝100两。

TEAM BATTLE清盘后，核对团队余额。到晚餐完成分配，原队伍正式解散，此后所有人各自为战。

银票均分 · 向上取整

个人银票＝⌈团队银票 ÷ 人数 ÷ 10⌉ × 10

每人所得向上取整到最近的10两整数倍，领取相同数量的10两银票；多发出的部分由工作人员补齐。

1000两 ÷ 6人 → 每人170两
实际发出1020两，工作人员补齐20两。

840两 ÷ 7人 → 每人120两
实际发出840两，无须补齐。

09 · DINNER · INDIVIDUAL STAGE

胡碟·摩登时代

Meccha Chameleon · 每桌随机2名潜伏者，身份通过上菜纸条产生。

🕵️

Meccha Chameleon

负责人：晚餐主持人时间：20分钟潜伏＋投票与核验最高奖励：潜伏者100两／普通玩家20两完成条件：晚餐个人游戏，不计入Bingo。⌄

所需物料

按各桌实际人数准备的上菜身份纸条（每桌2张潜伏者）、每名潜伏者1项秘密任务、投票纸、笔、计时器及个人余额表。

游戏流程

在自然聊天中完成秘密任务，或识别同桌真正的潜伏者。

  1. 按现场安排入座。每桌按实际人数准备外观一致的折叠上菜纸条，其中2张写潜伏者并附秘密任务，其余为普通玩家。每人随机领取，只看自己的身份。
  2. 主持人宣布开始后进行20分钟潜伏。潜伏者可通过自然聊天、提问和引导完成任务，不能亮出身份或要求别人配合。
  3. 任务只计算这20分钟内真实发生的行为；任务要求的参与人数不包括本人，不能交换身份或任务。
  4. 时间到即停止任务。每人独立投1票，写出最怀疑的1名同桌成员，不能投自己；多写、自投或无法辨认的票无效。
  5. 票收齐后统一公布身份。潜伏者收到3票及以上即暴露；少于3票为未被识破。
  6. 公开秘密任务，由同桌成员确认是否真实发生；有争议由工作人员最终判断，无法核实则不计完成。
  7. 普通玩家只要投中真实潜伏者就得20两，无须对方累计3票；潜伏者也投票，但不领取普通玩家抓人奖励。结算后更新个人余额。
银票结算潜伏者任务完成＋60两；完成且本人收到少于3票，再＋40两，最高100两。未完成0两。普通玩家投中真实潜伏者＋20两，投错0两。所有奖励归个人。

判定标准

潜伏者收到3票及以上为暴露；任务由同桌核实，有争议由工作人员最终判定，无法核实则不计完成。

禁止事项：不能串票、亮身份求配合、交换任务或与他人约定互相完成任务。

工作人员注意

按实际桌数与每桌人数准备身份纸条，每桌随机2名潜伏者。收齐投票后才公开身份，再核验任务、发个人银票。

结算例子：小王完成任务但收到3票，得60两；若只收到2票，则得100两。普通玩家小李投中小王，另得20两。
