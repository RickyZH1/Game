01麻将休息站休息区每局5分钟

休息区，与道具商店相邻；另留约2分钟入座、洗牌。

  1. 每桌4人，每人先交20两台费，再发牌。建议用去掉花牌的136张牌；庄家14张，其余各13张。
  2. 从庄家打出第一张牌起计时5分钟。轮到自己先摸1张，再打1张；可碰，可吃上家打出的牌，不设杠牌，不计番。
  3. 手牌凑成4组顺子或刻子，加1对相同牌即可胡；可自摸，也可胡别人打出的牌。不设七对等特殊牌型。首位合法胡牌者出现，该局立即结束。
  4. 多人同时胡同一张弃牌，从出牌者下家起按座次确定优先者。时间到只处理已经打出的最后一张牌，不再摸牌；未胡牌或牌摸完均为流局。

每桌台费80两，首位胡牌者拿走全部80两，即净赚60两；其余3人各净亏20两。流局时80两归官方。个人输赢计入所属队伍账户。

2套麻将、2张便携麻将桌、8把椅子、计时器、简化规则牌、记账表。

甲乙丙丁各交20两。第3分钟乙胡牌，乙领取80两；若5分钟内无人胡牌，4人的20两都不退。

02一尺花园餐桌潜伏者午餐20分钟＋5分钟揭晓

嵌入午餐；每队仅3人有任务。

  1. 每队秘密选出3名任务玩家，每人领取1张卡，其余5人没有任务。6队一共只需18张卡。大家事先知道存在秘密任务，但不公布谁拿了卡。
  2. 任务玩家在正常聊天中引导队友完成卡上的行为；不能展示卡片、直接说出任务要求，或与别人约定互相完成。
  3. 完成后悄悄记下时间和配合的队友，先不宣布。每位队员有1次指认机会，需准确说出某人正在诱导的行为；指认正确，该任务失败，错误则仅失去本次指认机会。
  4. 20分钟到时停止执行，再用5分钟逐张揭晓，由配合的队友确认。未完成或被准确识破的任务不得分。

每张任务成功赚30两；3张全部成功额外赚10两。每队最高100两，未完成不扣钱。

18张任务卡（同样3种任务各印6张）、笔；无需服务员参与。

小王的卡是“让一位队友主动提议合照”。他聊起上午没有全队照片，小李说“那我们拍一张吧”，任务成立；如果小王直接说“你快说我们拍照吧”，不算。

03乐高记忆银行脑力7分钟

固定站点；观察45秒，还原4分钟，其余讲解及核对。

  1. 用最多8块、有明显颜色区分的积木搭好模型。挑战散件与原模型的颜色、数量、形状完全一致，不混入多余积木。
  2. 全队观察原模型45秒，可以从前后左右看，不能触碰、拆开或拍照。模型放在有“正面”标记的底板上，记住方向。
  3. 工作人员遮住原模型。前2分钟由4人搭建、其余4人口头指导；后2分钟交换动手人员。4分钟结束立即停手。
  4. 每队可申请再看10秒，观察期间还原计时继续；不能带作品过去比对。裁判从标记的正面核对颜色、位置和层数。

赛前固定5个检查项，每项正确20两。再次观看扣20两，最低0两、最高100两。检查项对所有队伍相同。

原模型最多8块＋还原散件最多8块（两套合计最多16块）、2块带正面标记的底板、遮挡盒、收纳盘、判分照片。

示例用6块：底层从左到右红、黄、蓝；第二层绿色在红上、白色在蓝上；黑色在绿色上。5项可为：底层颜色顺序、绿色位置、白色位置、黑色位置、整体连接与层数。对4项得80两；若曾再看则得60两。

0424点挑战脑力6分钟

正式答题4分钟，其余讲解、发题与核对。

  1. 每队领取相同的10道题。8人可自由分工、交流，但不能使用计算器或手机搜索。
  2. 每道题给出4个数字，必须全部使用且各用一次，只能使用加、减、乘、除和括号，最终得到24。不能把两个数字拼成两位数。
  3. 在答题纸上按题号写出完整算式，只有口头说出答案不计分。同一题多种解法也只计1题。
  4. 4分钟到立即停笔。计算错误、漏用数字、多用数字都算该题错误，不扣其他题分数。

每答对1题赚10两，10题最高100两；答错不扣钱。

10题题单、核验过的答案表、6份答题纸、草稿纸、笔、夹板。

题目为1、2、3、4，可写“(1＋2＋3)×4＝24”。限时内做对7题，获得70两。

05公园投壶动作5分钟

平坦开阔处，投掷方向避开通道。

  1. 收纳筐固定不动，设置近线约1.5米、远线约2.5米。用软沙包投筐，全队先共用2次试投。
  2. 正式共10投：8人各投1次，另外2投由队伍自行指定人员。每次投之前可以重新选近线或远线。
  3. 脚站在所选线后，不能踩线或越线。近线命中得1点，远线命中得2点；越线该投记0点，不补投。
  4. 沙包最后留在筐里才算命中，弹出不算。投完一批由工作人员统一捡回，再继续，投掷时其他人不要进入目标区。

每点兑换5两，10投最高20点，即100两。

4个软沙包、1个折叠收纳筐、2个距离标记、计分表。

小李选择远线投进，得2点；小王近线投进，得1点。全队最终累计12点，获得60两。

06真人数字密码脑力5分钟

固定站点；5道题，每题最多30秒。

  1. 8人各拿0—7中的一张数字卡。工作人员读题后，持有关数字的人走出来，按答案顺序站好并举卡。
  2. 队员可以讨论、交换卡片，但一张卡只能出现一次。每题只有一次正式提交机会，全队说“提交”后裁判才判答案。
  3. 需要两位数时按从左到右排出十位、个位；题目也可要求组成符合条件的多位数。无关数字的队员留在后排。
  4. 每题30秒，到时未提交记该题错误。工作人员依次出完5题；全部题目须能用0—7这8张卡完成，不能要求重复数字。

每题答对20两，5题最高100两。

0—7数字卡共8张、5张题卡及答案、计时器。

工作人员问“7×8等于多少？”拿5的人站左边，拿6的人站右边，举成56并喊“提交”，赚20两。

07动作密码接力协作6分钟

两轮；每轮传递最多2分钟。

  1. 先统一5个动作：摸头＝1、拍肩＝2、叉腰＝3、张开双臂＝4、双手举高＝5。全员可先看动作表练习30秒。
  2. 8人排成一列，后面的人背向前面的人。只有第一人看5位密码卡，看完卡片收起。
  3. 第一人轻拍第二人，第二人才转身看动作；看完转回去，再叫第三人转身。每次只有相邻两人交接，其他人不能偷看、说话、口型提示或直接比数字。
  4. 每次交接最多完整重复演示一次。最后一人向裁判报出5位密码。第二轮换新密码、队伍反向传递。每轮到时仍未传到末位，该轮记0分。

每轮每个位置的数字正确赚10两。两轮共10个位置，最高100两。

动作对照卡、两张5位密码卡、计时器。

原密码是4-1-3-5-2，最后报成4-1-2-5-2，第1、2、4、5位正确，该轮得40两。

08森林特工接力创意7分钟

其中拍摄挑战5分钟；站点附近完成。

  1. 8人分成4对，手机固定拍摄一段连续视频。4对按顺序接棒，每对负责一个任务，其他人可指导但不能替代主角。
  2. 第1对用身体合成一棵树；第2对合成一个字母O；第3对摆出数字10；第4对表演一人按快门、另一人摆姿势，最后定格3秒。不能托举或攀爬。
  3. 每棒完成后退到画面一侧，下一对走到中央；最后8人一起入镜，摆出“电影海报”造型并保持5秒。
  4. 可在5分钟内重拍，但只能提交一条完整、不剪辑的视频。裁判按任务是否完成打分，不评价颜值、动作难度或拍摄审美。

前4棒每项20两；最后8人入镜并保持5秒再得20两。最高100两。

每队1部手机、1个手机支架、任务卡、计时器。

第一对一人伸展双臂做树枝，一人站旁边做另一半树冠；完成后换下一对。四棒都完成，但最后只有7人入镜，则得80两。

09抢瓶子大作战集体赛12—15分钟

6队同时参与的集体赛；两轮各4分钟。须使用独立开阔场地。

  1. 中央摆5个瓶子，周围等距设6个队伍专属收集区。8名队员在本队起点排队，每队任何时刻只能有1名搬运员在场内活动。
  2. 开始后搬运员快走前往中央或别队收集区，每趟最多拿1瓶，搬回本队区放下，再回起点与下一位击掌。全员按顺序轮流，不能连续派同一人。
  3. 可以拿别人已经放下的瓶子，但不能夺取别人手里的瓶子、护瓶、挡路或身体接触。同一个瓶子由先拿稳者带走，另一人必须放弃。
  4. 某队区域内同时放有全部5瓶，裁判确认后立即结束该轮；手里拿着的不算归位。4分钟无人集齐则喊停，按各区已放下的瓶数判定；手中瓶不算入任何队。第二轮轮换起始区域并把5瓶放回中央。

每轮集齐5瓶的队赚50两；到时无人集齐，瓶数最多队赚30两，并列各得30两。其余队0两。两轮每队最高100两。

5个相同塑料瓶（少量装水防风）、6个队伍区标记、中央标记、计时器；建议2名裁判。

1队已经有4瓶，轮到小王出发。他从2队区域拿走1瓶并放回本队，第5瓶落地且裁判确认时，1队获胜。如果回来途中本队另1瓶被拿走，则仍只有4瓶，未获胜。

10情报拼图脑力6分钟

其中正式讨论4分钟。

  1. 8人每人领取1张线索卡，只能自己看。线索可以口头复述，但不能展示或交换卡片。全队领取4张颜色卡和1—4号位置表。
  2. 队员轮流说出自己掌握的信息，共同把红、黄、蓝、绿4张卡排进正确位置。可以用纸笔记录，所有人都可参与讨论。
  3. 4分钟结束前提交最终排列，提交后不能修改。每队可申请一次提示，工作人员只读预先准备好的同一条提示。
  4. 正式题目须提前验证只有一个答案。裁判按4个位置逐项核对，不能临时改变答案或提示难度。

每个位置正确赚25两；用提示扣20两，最低0两，最高100两。

8张线索卡、4张颜色卡、1—4号位置表、答案与提示卡、纸笔。

一人知道“蓝在最右边”，另一人知道“黄紧挨在红的右边”，第三人知道“绿在黄和蓝之间”。结合其他线索，排出红—黄—绿—蓝。4个位置全对得100两。

11隐藏BOSS寻踪寻踪6分钟

搜索范围在站点附近约30—50米，步行可达。

  1. 每队领取一张现场固定物体的局部照片和搜索范围图，根据细节寻找对应物体。不能进入建筑、翻越围栏或移动现场物品。
  2. 找到后按任务卡要求，从目标上读取文字、数字或图案信息，算出一个4位密码；不得直接询问其他队的答案。
  3. 搜索满2分钟仍找不到，可以向裁判领取明确的位置提示，计时继续。队伍找到目标后仍须自行解题。
  4. 6分钟内回到裁判处提交一次答案，4位都要写出，前导0也要保留。工作人员提前踩点核对实物，目标变化时统一换备用题。

每位密码正确赚25两；使用位置提示扣20两。最低0两、最高100两。

现场局部照片、范围图、解码题卡、答案卡、备用题。可用手机展示。

示意题：目标牌有4行信息，按顺序数每行的圆形图标，数量为2、0、3、1，就提交2031。此例仅说明解法，正式题依据现场实物编写。

12买大买小运气4分钟

休息区或独立运气站；每队限一场。

  1. 8人分成4对，玩4轮，每轮换一对作决定，其他人可给意见。骰子1—3算“小”，4—6算“大”。
  2. 每轮先说清楚押大还是小，以及下注10两或20两；4轮中最多有1轮可以改押50两。裁判记下后才可以摇骰子，不能事后改注。
  3. 骰子放在透明带盖盒中摇，停稳后一起看点数。押对净赚下注额，押错扣掉下注额。
  4. 每轮讨论最多20秒，超时未作决定视为跳过该轮，收益0两。下注额不能超过队伍现有余额；余额不足10两则跳过。

一轮最多押50两且整场仅一次。4轮最高净赚110两，也可能净亏110两。

1颗骰子、1个透明带盖盒、大/小标记、记账表。

第一轮押大20两，摇出5，账户增加20两；第二轮押小10两，摇出6，账户扣10两，两轮合计净赚10两。

13见好就收运气4分钟

两轮；每队限一场。

  1. 8张同背卡包含6张金币、2张炸弹，充分洗牌后背面朝上。第一轮由4名队员依次翻牌，第二轮换另4人。
  2. 翻到金币，本轮暂存奖金增加20两。队伍要在10秒内决定“收钱”或“继续”，意见不一由队长拍板；超时默认收钱。
  3. 选择收钱，本轮奖金入账并结束本轮；继续则翻下一张。翻到炸弹，本轮暂存奖金清零并立即结束，但已入账银票不受影响。
  4. 每轮最多翻4张；连续4张都是金币则自动存入80两。每轮结束将所有8张卡放回并重新洗牌，第二轮重新开始。

每轮最高80两，两轮最高160两；炸弹不扣队伍原有余额。

8张同背卡（6金币＋2炸弹）、记账表、计时器。

连续翻出3张金币，暂存60两。此时收钱就赚60两；如果继续翻到炸弹，本轮得0两。如果第4张仍为金币，则自动赚80两。

14禁词情报员表达5分钟

8人依次描述，每人20秒。

  1. 每人轮流做一次情报员，只由自己看题卡，其他7人猜。卡片写有1个目标词和3个禁词。
  2. 情报员只能用语言解释，不能说目标词中的任何一个字、3个禁词、谐音，或用外语直接翻译；不能展示题卡、写字或比划答案。
  3. 例如目标是“火锅”，禁词是“辣、涮、聚餐”，描述时既不能说“火”“锅”，也不能说这3个禁词。
  4. 猜中立即换下一位。说出禁词该题作废；20秒未猜中或主动放弃也结束该题，不补题。8人各1题，队友可自由抢答。

每猜对1题赚10两；8题全对额外20两，最高100两。

8张正式题卡、备用题卡、计时器；各队用同一套题，等待队伍不能旁听。

目标“地铁”，禁词“车、地下、站”。可以说“我每天通勤会乘坐的一种轨道交通工具”。队友猜出“地铁”得10两；若描述时说“坐车”，该题作废。

午餐潜伏者 · 18张任务卡怎么准备

以下3种卡各印6张。每队各拿A、B、C一张，秘密发给3名不同成员。每队任务相同，难度一致；无需给另外5名队员发空白卡。

A卡 · 合照发起人

引导一位队友主动提出“大家拍一张合照”。同义表达也算；你不能先直接要求对方提议拍照。

B卡 · 童年小吃

让一位队友说出自己小时候喜欢的一种小吃，并讲出一个与它有关的小回忆。只有报出小吃名字不算。

C卡 · 默契手势
