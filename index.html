怎么盖章、申报与计算排名＋

固定两个角位

所有队伍的Focus Hunter固定左上角，Blind Shape固定右下角；卡片发放后不能自行调换位置。位置只决定连线，不改变挑战次序：Focus Hunter统一先做，其余八项解锁后自由安排。

出发前

队长确认原始队员人数与队伍编号，先领取500两、固定排列的Bingo卡和队号牌。专属美食卡与隐藏点线索在三组PK全部结束后统一发放，避免队伍提前踩点。网页用于查阅，不自动记分；纸卡、裁判记录和群消息作为比赛依据。

第一个任务与解锁

所有队伍先参加Focus Hunter。三组依次对战，未上场及已打完的四队观看。每组双方角色完成后先盖章；必须等三组全部结束，主持人统一发出“解锁”口令，六队才能开始其余八项任务。

一个格子怎样算完成

六个负责人关卡须全队到场，按规则完成规定轮次并由负责人登记；美食任务须完成本队专属卡片；Focus Hunter须完成双方角色。隐藏点位是唯一自助任务，须在活动群提交合格照片。分数由表现另算，不要求满分。

全队到场与排队

不能拆队同时做不同任务，也不能派人提前占位。站点忙时全队排队，或共同前往其他任务；离开队列需重新排队。每格只结算一次，额外重试仅按已购道具执行。

首次Bingo：4项完成＋3格连线

必须同时满足两项：①至少4个不同任务已核验完成，Focus Hunter也计入；②已完成格中至少有一条横线、竖线或对角线。重复挑战同一任务不增加任务数。只完成3项即使连线也不能申报，继续完成任意第4项后才取得资格。

取得资格后，队长在活动群提交“队伍号＋首次Bingo＋已完成任务至少4项”及可核验九宫格／记录。按首次符合两项条件的有效申报消息顺序排名，不按三格提前连线时间、不按工作人员审核先后排名。提前申报无效，完成第4项后须重新提交；一次多条线仍只领取一次。

Full House与截止

9格都真实完成后另行申报，审核通过额外120两，每队一次。02:00停止新任务和新提交；截止前的合格申报可在之后审核，按原提交时间排序。消息时间显示相同时用群消息先后顺序，不凭审核先后改变排名。

例子：三格连线还不够

1队第一行是Focus Hunter、Brick Bank和美食。三项完成虽已连线，仍不能领首次Bingo奖励；再完成Hide and Seek，共4项后，才可提交有效申报。如果此时是第二支合格申报队伍，额外拿80两。Blind Shape固定右下角，但可在开场后自行安排挑战顺序。

美食任务的执行与审核步骤＋

出发前确认

每队只领取一张专属任务卡，先核对门店数量、指定品类和总款数。六张任务卡彼此不同，不能临时交换，也不能用其他队的门店替代。

到店与品尝

全队共同到店，按任务卡选购并共同品尝。每家门店至少拍一张包含清晰招牌、指定食物、队伍编号和队员的照片；刨冰等不便携带的食物只需现场品尝和拍照。

带回推荐

完成全部品尝后，全队投票选出一款最符合任务主题的小吃。记录员在任务卡上手写一句具体推荐理由；任务要求“带回终点”的小吃须妥善保存并在终点出示。

发送格式

完成后将材料一次性发到活动群，配文“3队｜且介亭三店三艺｜3家门店已完成｜推荐：××”。Seven核对门店、数量、工艺或品类、合照和推荐理由，全部符合才盖章。

门店关闭或售罄

联系Seven统一安排替代方案，队伍不能自行更换门店、食品或任务；全部要求完成才得100两，未完成得0两。

补交与安全

缺门店、缺食物照片、人数不足或推荐理由不清，可在02:00前补交；以第一次完整合格材料的时间为准。排队时不堵店门，不边走边吃，过敏或忌口人员可不试吃但须随队到场。

例子

2队任务是“朝花夕拾弄堂百味图鉴”：在虹口糕团厂选2款、祥德市集选2款，共4款；全队品尝后选出1款带回，并写一句怀旧感推荐理由，材料齐全得100两并完成九宫格中的美食格。

使用细则与补充建议＋

购买和交卡

沿用每队每种最多1张、先付银票再领卡的规则；数量为全场总量。卡只能用一次，交负责人注销。不同类型可用于同一关，但不能突破活动总截止时间。

加时和重启

补充建议：加时统一为30秒；须在指定计时结束前交卡。重启恢复原始时限，不再次叠加已用过的加时；重启成功替换该题／轮的0分。Code Talker可补全对奖励，BSO Code Breaker不补90秒速度奖。

统一结算

先计算游戏得分与全对奖励，再用双倍卡：额外奖＝原奖与100两中较小者。例如BSO Code Breaker得120两，双倍后220两；购卡70两已经记支出，不再重复扣。

情报卡

补充建议：隐藏提示按最终任务奖励扣减，不重复收现金。无卡两级提示后入账40两；有情报卡两级提示后入账70两，卡费20两另记。

带入个人阶段的卡

银票余数怎么处理

补充建议：工作人员用个人账本记到0.01两，先每人分相同金额，尾差留官方不参与竞拍。例如1000两÷6人，每人166.66两，尾差0.04两留官方；不通过抽签让某个人多拿一张。

五桌座位

末名队6／7／8人时，分别按2-1-1-1-1、2-2-1-1-1、2-2-2-1-1随机入桌。末名并列先看真实完成格数，仍同则抽签，仅决定座位。五桌都从所有在座者中抽2人，身份完全随机。

完成核验

任务要求的人数不含潜伏者自己，只算20分钟内行为。投票收齐后持卡人描述过程，由相关当事人确认，主持人最终核验；有争议且无法证实则不计完成。不能提前亮身份、交换卡或约定配合。

PERSONAL AUCTION & REDEMPTION

先拍卖，再兑换

只使用个人银票。可以竞拍、直接等兑换，或保留银票；不能与他人合并出价。

实物公开拍卖

  1. 主持人逐件展示LEGO小礼物、咖啡券、零食礼包、小盲盒或实用小物，并宣布该件起拍价。
  2. 个人公开喊价，每次加价至少10两；报价不能超过本人当前可用余额。
  3. 有效喊价后不能撤回。主持人确认最高报价，三次倒数无人再加价便落槌；同时喊同价以主持人先确认者为准。
  4. 最高报价者支付银票，领取实物；其他未拍到的人不扣款。无人出价则流拍。
  5. 每件成交立即更新个人余额，再开始下一件；全部拍卖结束后才开放兑换。
